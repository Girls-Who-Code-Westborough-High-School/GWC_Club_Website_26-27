# GWC Website 2026-27

## Four-page structure

| Page | File | Purpose |
| --- | --- | --- |
| Home | index.html | Welcome visitors and introduce the club |
| About | about.html | Explain the club, activities, and meeting information |
| Members | members.html | Display leadership and member cards |
| Projects | projects.html | Share project photos, videos, and descriptions |

## Shared across all pages

- Header: club name and links to Home, About, Members, and Projects.
- Footer: club Instagram link (URL to be supplied).
- Shared styling: css/styles.css.
- Optional interactions later: js/script.js.

## Home - index.html

1. Title: Girls Who Code.
2. Club group photo.
3. Short introduction to the club.

## About - about.html

1. Link to the official Girls Who Code website.
2. Mission statement quote with attribution.
3. Official GWC image or logo.
4. What we do and what we are working on now.
5. Upcoming activities and meeting information.
6. Calendar.
7. Club contact information.

## Members - members.html

1. Page heading: Our Members.
2. Member-card gallery, including 2026-27 leadership roles.
3. Each card: name, role, photo/avatar, and member-chosen content.

Cards can be added as members finish them; the page does not need to wait
for every submission. Collect each member's HTML, CSS, and media files.
When combining cards, keep one page document structure and scope custom
styles to each card so they do not affect other members' cards.

## Projects - projects.html

1. Page heading: Our Projects.
2. Repeated project entries with a title, description, and photos/videos.
3. Alternate media and description sides on larger screens.
4. Stack each entry vertically on phones.
5. Add scrollable media galleries after the basic layout works.

Add new entries to this page as projects are completed.
Project categories and individual project pages are optional future additions.
